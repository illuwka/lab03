# lab-03
# LOQ Team

Сайт для купівлі скінів Counter-Strike. Лабораторна робота №3 (Flask).

## Опис

Ми створюємо багатосторінковий вебсайт, на якому можна переглянути каталог скінів на зброю в комп'ютерній грі CS, ознайомитися з категоріями та знайти контактну інформацію. Сайт має адаптивну верстку й коректно відображається як на смартфонах, так і на персональний комп'ютерах.

## Сторінки

- **Головна** — вступний блок
- **Магазин** — каталог скінів з їхньою ціною, зображеннями
- **Про нас** — інформація про нашу команду з посиланнями на каталог і Зворотній звязок
- **Зворотній зв'язок** — пошта, телефон, графік роботи

## Технології

- Flask
- HTML

## Запуск проєкту

1. Клонуйте репозиторій:

```bash
git clone https://github.com/illuwka/lab-03.git
cd lab-03
```

2. (Рекомендовано) створіть і активуйте віртуальне середовище:

```bash
python -m venv venv
# Windows
venv\Scripts\activate
# Linux / macOS (bash/zsh)
source venv/bin/activate
```

3. Встановіть Flask:

```bash
pip install flask
```

4. Запустіть застосунок:

```bash
python app.py
```
