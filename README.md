# AVANGARD SHOP

Навчальний сайт магазину комп'ютерів і ноутбуків. Лабораторна робота №3 (Flask).

## Опис

AVANGARD SHOP — багатосторінковий вебсайт, на якому можна переглянути каталог комп'ютерної техніки, ознайомитися з категоріями та знайти контактну інформацію. Сайт має адаптивну верстку й коректно відображається як на комп'ютері, так і на мобільних пристроях.

## Сторінки

- **Головна** — вступний блок і швидкий перехід до розділів
- **Каталог** — ноутбуки та комп'ютери з характеристиками й цінами
- **Категорії** — ноутбуки, комп'ютери, техніка для навчання й роботи, техніка для ігор
- **Про нас** — інформація про магазин
- **Контакти** — пошта, телефон, графік роботи

## Технології

- Python 3
- Flask
- HTML 
- CSS

## Запуск проєкту

1. Клонуйте репозиторій:

```bash
git clone https://github.com/The-Avangard/lab-03.git
cd lab-03
```

2. (Рекомендовано) створіть і активуйте віртуальне середовище:

```bash
python -m venv venv
# Windows
venv\Scripts\activate
# Linux / macOS
source venv/bin/activate
```

3. Встановіть Flask:

```bash
pip install flask
```

4. Запустіть застосунок:

```bash
python app.py
```
